Changes made (CC BY-SA 4.0 §3(a)(1)(B)):

  * Selected 200 of the 1,034 dev questions: stratified by Spider's own
    hardness label (easy / medium / hard / extra), split by database into a
    `hillclimb` half and a disjoint `heldout` half. Questions and gold SQL are
    verbatim.
  * Dropped questions whose gold result is empty, a single 0 or NULL, all
    NULL, or changes when the database's rows are stored in reverse order.
    Dropped the `wta_1` database, which has no rows in the source dump.
  * The databases were not taken from the original .sqlite files (distributed
    only via Google Drive). They were recovered from InterCode's MySQL
    conversion of the Spider dev databases and re-imported into SQLite. Row
    counts can differ from the original release, and some key column types
    were harmonized by InterCode before conversion. Gold results were
    re-computed on this data and pinned (goldResultSha256).

The full procedure is eval_harness/build_nl2sql_golden.py.
